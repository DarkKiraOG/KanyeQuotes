# KanyeQuotes

A Python application that fetches and displays random Kanye West quotes using the `requests` library.

## Features
- Fetches a random quote from the Kanye Rest API
- Displays the quote using the tkinter library

## Installation
Clone the repository:
git clone https://github.com/DarkKiraOG/KanyeQuotes.git
cd KanyeQuotes

Ensure Python is installed, then run the application:
python main.py

## Usage
- Upon running, the application will display a random Kanye West quote on another screen
- Click on Kanye to get a new quote

## Notes
- The application requires the `requests` library; install it using pip install requests
- Designed for educational purposes and to bring some Kanye wisdom to your terminal
